SANSXML VPN STORE — SATU DOMAIN (REVISI ROUTING)

Domain target: vpn.id-sansvpnstore.cloud
OS target: Debian 12

Port publik:
- TCP 22: SSH biasa (harus dipertahankan; installer ini tidak dimaksudkan mengganti sshd).
- TCP 80: Nginx HTTP, Xray WebSocket path /vmess, /vless, /trojan-ws; SSH WebSocket path /ssh dan fallback /.
- TCP 443: sslh menerima koneksi dan mengarahkan TLS berdasarkan SNI ke Nginx TLS; Nginx TLS meneruskan /ssh ke SSH-WebSocket backend 127.0.0.1:700 dan path Xray ke backend masing-masing.

PENTING:
1. Ini adalah pengaturan berbasis WebSocket/path. SSH TLS mentah tidak dapat dibedakan dari Xray TLS pada hostname/SNI yang sama hanya dengan path; gunakan SSH WebSocket melalui TLS pada path /ssh.
2. Skrip ini belum diuji pada VPS produksi. Sebelum menjalankan, buat snapshot/backup dan pertahankan sesi SSH aktif. Pastikan backend SSH-WebSocket benar-benar berjalan pada 127.0.0.1:700.
3. Setelah instalasi, validasi `nginx -t`, status `nginx`, `sslh`, `ssh`, `ssh-ws`, dan `xray`; lalu uji login SSH baru sebelum menutup sesi lama.
4. Jika konfigurasi sslh di VPS berbeda dari yang diasumsikan installer, hentikan dan periksa konfigurasi terlebih dahulu. Jangan menganggap semua koneksi berhasil hanya karena sintaks lolos.
